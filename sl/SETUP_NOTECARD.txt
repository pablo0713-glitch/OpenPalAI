========================================
  OpenPalAI
  AI Companion for Second Life & Discord
========================================

This framework turns a Second Life avatar into a live AI companion
powered by Claude (Anthropic), GPT-4, Gemini, Grok, or a local model
via Ollama. The agent remembers conversations, searches the web, sees
nearby avatars, reads ambient chat, and responds to IMs or local chat
triggers — all from a self-hosted server you run yourself.

Full documentation, setup guide, and source code:
https://github.com/pablo0713-glitch/openpalai-companion-agent


----------------------------------------
  VIEWER REQUIREMENT
----------------------------------------

YOU (the user) can log in with any viewer — Firestorm, Alchemy, the
official SL viewer, whatever you prefer.

THE AGENT'S AVATAR must run Cool VL Viewer.

The primary in-world interface is a native Lua automation script that
runs inside Cool VL Viewer on the agent's side. It handles avatars,
environment, agent state, chat, and direct IMs at the viewer level —
with no LSL memory limits and no /42 channel needed.

An LSL HUD script is also included for environment object scanning and
as a fallback if Cool VL Viewer is not available for the agent's avatar.
Cool VL Viewer for the agent's avatar will eventually be required.

Cool VL Viewer: https://sldev.free.fr/

----------------------------------------
  SETUP OVERVIEW
----------------------------------------

Full step-by-step instructions are at the GitHub link above.
The short version:

1. INSTALL THE SERVER
   Clone the repo, install Python dependencies, and run the setup
   wizard at http://localhost:8080/setup to configure your AI model,
   persona, and credentials. For 24/7 use, deploy to a VPS using the
   containerized setup described in:
   Cloud-Deployment-And-Persistence-Guide.md (in the repo root).

2. INSTALL THE LUA SCRIPT (Cool VL Viewer)
   The server generates lua/agent_companion.lua with your credentials
   filled in. Copy it to your Cool VL Viewer user_settings folder as
   automation.lua. The viewer loads it automatically on startup.

   See lua/README.md in the repo for exact OS paths and a warning
   about same-PC setups where both your viewer and the agent's viewer
   run on the same machine.

3. INSTALL THE LSL HUD (optional / object scanning)
   If you are not using Cool VL Viewer, or want object scanning in
   addition to the Lua script, paste lsl/companion_bridge.lsl into
   a prim and wear it as a HUD. The server generates this file with
   your credentials pre-filled.

4. TALK TO YOUR AGENT
   Private IM (Lua — no channel prefix needed, just IM the avatar):
     Hey, what do you think of this sim?

   Private channel via HUD (LSL fallback):
     /42 Hey, what's going on here?

   Local chat trigger (public — reply is public):
     Hey [AgentName], what's the vibe in here?
